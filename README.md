# Telegram AI Bot Q

Telegram-бот на Python с aiogram 3 и Groq API.

## Возможности

- Отвечает на текстовые сообщения с помощью языковой модели.
- Сохраняет последние 4 пары сообщений для контекста каждого пользователя.
- Команда `/clear` очищает историю диалога.
- Секретные ключи берутся из переменных окружения.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Задать переменные окружения `TELEGRAM_BOT_TOKEN` и `GROQ_API_KEY`, затем запустить:

```bash
python main.py
```

На хостинге добавь обе переменные в раздел Environment Variables / Secrets. Не публикуй значения ключей в репозитории.

## Важно

История хранится в оперативной памяти процесса и сбрасывается при перезапуске. Для постоянной доступности нужен хостинг, поддерживающий непрерывно работающие фоновые процессы.
